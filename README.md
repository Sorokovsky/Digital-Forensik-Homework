# ЗВІТ ПРО РОЗСЛІДУВАННЯ: BSides Amman 2021 — Windows Forensics Case

Аналітик: Амар

Дата розслідування: 21.08.2026

Інструменти: Autopsy v4.23.1

Номер документа: 01.001

## 1. Короткий огляд

Вам надано систему, що використовувалася для незаконної діяльності, під час якої користувач отримав доступ до конфіденційних файлів, не маючи на це відповідних повноважень. Система має два облікові записи користувачів, які є основними об'єктами розслідування: joker та IEUser. Ваше завдання — виявити ці конфіденційні файли та надати докази несанкціонованого доступу.

## 2. Мета розслідування

- визначити конфедиційні файлів, котрі отриманні несанкціонованим шляхом;
- надати докази несанкціонованого доступу до цих файлів.

## 3. Методологія

- створення образу: "BSidesAmman21.E01" та завантажено в Autopsy;
- модулі обробки: метаданні, файлова система, аналізатор електронної адреси, часова шкала, нещодавня активність;
- Аналіз даних: файли .xls, файли .pst(Outlook), видалені файли та часова шкала.
